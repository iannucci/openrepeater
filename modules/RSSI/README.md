# MODULE_RSSI

This module enables users to get a signal report (in S-units)

To format a .zip file so that this module can be read and installed by
OpenRepeater, 

On the Mac, open a terminal window

cd into the folder to be zipped (not above the folder, in it)

Enter the command 

zip -r MODULE_RSSI-1.0.zip . -x '**/.*' -x '**/__MACOSX'

(replacing the RSSI with the module name and 1.0 with the correct version)
